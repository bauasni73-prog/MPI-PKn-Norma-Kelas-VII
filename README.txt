MPI PENDIDIKAN PANCASILA / PKN KELAS VII
Materi: Macam-Macam Norma
Kurikulum Merdeka - Fase D

ISI PAKET
- index.html : file utama MPI. Tidak membutuhkan instalasi atau database.

CARA MEMBUKA SECARA LOKAL
1. Ekstrak ZIP.
2. Klik dua kali index.html.
3. File akan terbuka di browser seperti Chrome, Edge, atau Firefox.

CARA MENJADIKAN MPI ONLINE (pilih salah satu layanan hosting statis)

A. Netlify Drop (cara paling mudah)
1. Ekstrak ZIP ke komputer.
2. Buka https://app.netlify.com/drop
3. Seret folder MPI_PKn_Norma_Online yang berisi index.html ke area upload.
4. Tunggu proses selesai. Netlify akan memberi alamat website yang dapat dibagikan.
5. Simpan alamat tersebut untuk dibagikan kepada peserta didik.

B. GitHub Pages
1. Masuk ke https://github.com dan buat repository baru.
2. Unggah index.html dari folder hasil ekstraksi ke repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Setelah publikasi selesai, buka alamat Pages yang ditampilkan GitHub.

CATATAN
- ZIP ini adalah paket situs statis; jangan mengunggah file ZIP sebagai halaman web. Ekstrak terlebih dahulu atau gunakan layanan yang menerima folder situs.
- MPI dapat dibuka offline setelah file index.html diunduh.
- Jawaban dan skor berjalan di browser pengguna; paket ini tidak menyimpan nilai ke server atau mengirim nilai guru secara otomatis.
